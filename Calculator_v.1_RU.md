### **2. Краткое описание проекта.**

• Проект Calculator v.1 – это многофункциональное десктопное приложение на Python с графическим интерфейсом, предназначенное для выполнения широкого спектра математических операций. 

• Программа объединяет функции простого, инженерного и научного калькулятора, предоставляя инструменты для арифметических вычислений, работы с простыми числами, решения уравнений, тригонометрических преобразований и других математических задач в удобном и современном интерфейсе с сохранением истории работы.

### **5. Инструкция по использованию.**

• Перед использованием приложения важно понять как оно работает. Первым делом следует ознакомиться с функциями, которые находятся в левой панели экрана. 

• После определения нужно нажать на нужную функцию и перейти на правую панель, где появятся строки для ввода чисел, чтобы провести выбранную операцию. 

• Чтобы было понятнее какая вводимая буква что обозначает, прямо под строками ввода есть подсказка в виде формулы с теми же переменными, что задаются пользователем.

• После ввода требуется провести вычисление, нажав на кнопку ниже. После получения результата можно выбрать новую функцию, либо стереть нынешние вычисления кнопками в нижней панели. 

• Все вычисления запоминаются в истории, список которой доступен в верхнем правом углу. Ее можно скопировать или очистить.

• Языки программирования: Python.

• Библиотеки: tkinter, math, json, os, typing.

### **3. Архитектура проекта.**

• Проект использует подход Model-View-Controller (MVC) внутри одного главного класса Calculator.

• Модель (Model) – это математические функции, такие как сложение, поиск НОД, решение уравнений. Они находятся в методах класса.

• Представление (View) – это весь графический интерфейс: кнопки, поля ввода, панели, которые создаются с помощью tkinter.

• Контроллер (Controller) – это логика, которая связывает интерфейс и вычисления. Она обрабатывает нажатия кнопок, ввод данных и отображение результатов.

### **4. Структура проекта.**

• Проект состоит из одного основного файла: calculator.py.

• В этом файле находится весь код: класс Calculator, настройки интерфейса и все математические операции.

• Для работы нужна только стандартная библиотека Python, ничего дополнительно устанавливать не требуется.

### **5. Ключевые компоненты системы.**

• Главный класс Calculator – управляет всем приложением.

• Цветовая схема (словарь colors) – хранит все цвета для интерфейса в темном стиле.

• Текущее состояние: выбранная операция, список полей для ввода, история вычислений.

• Специальные переменные для отображения (result_var, expression_var) – показывают результат и формулу.

• Менеджер истории – сохраняет историю в файл calc_history.json и загружает ее при запуске.

• Математический движок – более 20 методов, которые выполняют все операции от сложения до решения квадратных уравнений.

### **6. Реализация пользовательского интерфейса.**

• Интерфейс построен на библиотеке tkinter.

• Стиль задается вручную через цвета и шрифты, без использования тем.

• Интерфейс разделен на три основные части:

• Верхняя панель с названием и кнопками "Сброс" и "История".

• Левая панель со списком всех операций, разбитых на категории.

• Правая панель с областью для ввода данных и областью для вывода результата.

• Элементы интерфейса динамические: количество полей ввода меняется в зависимости от выбранной операции.

• Есть эффекты при наведении на кнопки, поддержка горячих клавиш.

### **7. Процесс разработки.**

• Сначала был создан базовый каркас окна на tkinter.

• Затем поочередно были написаны все математические функции.

• После этого был разработан интерфейс: разметка, кнопки, поля ввода.

• Далее интерфейс был подключен к математическим функциям.

• В конце были добавлены дополнительные системы: история, обработка ошибок, диалоговые окна.

• Весь процесс сопровождался тестированием операций и исправлением ошибок.

### **8. Основные сложности и способы их решения.**

• **(1)** Сложность: как сделать разное количество полей ввода для разных операций.

Решение: функция select_operation создает нужное количество полей ввода динамически и запоминает их в список.

• **(2)** Сложность: как обрабатывать специальный ввод, например, "pi" или дроби "1/2".

Решение: в методе calculate добавлена проверка строки перед преобразованием в число.

• **(3)** Сложность: как сохранять историю вычислений между запусками программы.

Решение: история сохраняется в файл в формате JSON при каждом вычислении и загружается при старте.

• **(4)** Сложность: как корректно обрабатывать все возможные ошибки пользователя.

Решение: все вычисления обернуты в блок try-except, который ловит ошибки и показывает понятные сообщения.

### **9. Текущие ограничения проекта.**

• Весь код находится в одном файле и одном классе, что может усложнить дальнейшее расширение.

• Результаты всегда выводятся в виде десятичных дробей, обыкновенные дроби не поддерживаются.

• Интерфейс имеет фиксированный темный стиль, сменить тему или цвета нельзя.

• Если вычисление будет очень долгим, интерфейс "зависнет" на это время.

• Поддержка специального формата ввода ограничена (например, нельзя ввести сложное выражение).

• Интерфейс только на русском языке, переключение на другие языки не предусмотрено.
